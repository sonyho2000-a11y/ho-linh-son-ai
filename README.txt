HO LINH SON AI – Website mẫu v1.0

Cách chạy:
1. Giải nén thư mục.
2. Mở file index.html bằng Chrome/Edge.
3. Không cần cài đặt máy chủ.

Đây là prototype chạy cục bộ:
- Dashboard
- Lớp học
- Bài học
- Học sinh
- Giao bài A/B/C
- Phân tích mã lỗi
- Kho lệnh AI
- Hồ sơ giáo viên
- Dark mode, tìm kiếm, sao chép lệnh

Dữ liệu hiện tại là dữ liệu minh họa. Chưa kết nối Google Classroom/Forms/Sheets thật.
